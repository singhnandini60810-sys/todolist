# Advanced To-Do App
To visit: https://singhnandini60810-sys.github.io/todolist/
A simple yet powerful Advanced To-Do List web application built using HTML, CSS, and JavaScript.
This app helps users manage their daily tasks efficiently with features like task priorities, due dates, progress tracking, and dark mode.

The application stores tasks using LocalStorage, which means your tasks remain saved even after refreshing or closing the browser.

---

# Features

## Add Tasks

Create new tasks quickly using the input field.

## Due Dates

Assign a due date to tasks to keep track of deadlines.

## Priority Levels

Tasks can be categorized by priority:

* Low Priority
* Medium Priority
* High Priority

Each priority is visually indicated with a colored border.

## Mark Tasks as Completed

Click on a task to mark it as completed. Completed tasks appear with a strikethrough.

## Edit Tasks

Edit any task using the edit button.

## Delete Tasks

Remove tasks instantly using the delete button.

## Progress Tracker

Displays how many tasks are completed out of the total tasks.

Example:

Completed: 3 / 7 Tasks

## Clear Completed Tasks

Remove all completed tasks with one click.

## Dark Mode

Switch between light mode and dark mode for a better viewing experience.

## Local Storage

All tasks are saved automatically in the browser using LocalStorage so your data persists after refresh.

## Keyboard Support

Press Enter to quickly add tasks without clicking the button.
