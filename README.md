# 📝 To-Do List App

A simple and beginner-friendly To-Do List web application built using pure HTML, CSS, and JavaScript.

This project was created using only Notepad and runs directly in the browser.

---

## 🚀 Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- Tasks saved using Local Storage
- Works completely offline
- No external libraries used

---

## 🛠 Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

---

## 📂 How to Run

1. Download the project files.
2. Open `index.html`.
3. Double click the file.
4. It will open in your default browser.

No installation required.

---

## 💡 How It Works

- Tasks are stored in the browser using Local Storage.
- When the page reloads, tasks are automatically loaded.
- Clicking a task marks it as completed.
- Clicking "X" deletes the task.
